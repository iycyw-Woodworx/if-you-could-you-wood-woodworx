# Custom Grain Woodworks — Free Website

This is a complete, responsive static website built from your woodworking photos.

## Before publishing
Open `script.js` and change:
- BUSINESS_NAME
- BUSINESS_EMAIL
- BUSINESS_PHONE

## Free hosting
This site has no paid software or server requirements. It can be hosted for free with a static-site host such as GitHub Pages or Cloudflare Pages.

## Important
The quote form uses the visitor's email app (mailto), so it does not require a paid form service.

## Files
- `index.html` — website
- `style.css` — design
- `script.js` — business contact details + quote form
- `images/` — portfolio photos
